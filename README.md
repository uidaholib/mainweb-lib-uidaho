# mainweb-lib-uidaho

<https://www.lib.uidaho.edu>

A jekyll project to build University of Idaho Library's main website, using a minimal infrastructure static web approach.

The website theme reflects the main [University of Idaho](https://www.uidaho.edu/) style, but is reimplemented using a completely different stack and is adapted for the Library's context.
For more information about the stack see [about this website](https://www.lib.uidaho.edu/about/tech.html).
Our article ["Using Static Web Technologies and Git-based Workflows to Re-Design and Maintain a Library Website (Quickly) with Non-Technical Staff", College & Undergraduate Libraries](http://doi.org/10.17613/v30m-mx03) describes an earlier redesign using static web methods.
