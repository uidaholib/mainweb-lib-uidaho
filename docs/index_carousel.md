# Index Carousel

The home page features a carousel feature that is regularly updated for major events, prompting new services, or semester resources.
The slides are set in "_data/index_carousel.csv". 

Guidelines: 

- Avoid having too many slides, 5-6 is normal.
- Keep image sizes small. The image is stretched to cover a 16:9 ratio rectangle with a max size of about 400px wide by 200px tall. Digital Collection "small" images are the correct size.
