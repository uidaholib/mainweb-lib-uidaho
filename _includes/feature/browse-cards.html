{% comment %} Browse Cards include takes a data CSV and generates a basic filterable, sortable browse feature. Each record is represented as a card. The CSV can have the columns title,description,link,link-text,image-src,image-alt,popularity-rank Only "title" is required. The rows are rendered in the order they appear in the CSV. "popularity-rank" is a number (1 = most popular) that drives the default "Most Popular" sort; rows without it sort last. Use like: {% include feature/browse-cards.html data="find_index" %} Options: - "data" = the name of the CSV in the "_data" folder, given without the file extension, e.g. "find_index". - "search" = false to opt out of adding a search box. - "sort" = false to opt out of adding sort options. - "label" = the plural noun used in the search box, result count, and no results message, e.g. "collections" (default "resources"). - "heading_level" = the heading element used for the card titles, "h2", "h3", etc (default "h2"), set for correct heading order on the page. A long description is clipped so the cards stay a scannable height, and the rest of it is shown when the card is hovered or tabbed into. The open card floats above its place in the grid, so the cards around it do not move, and Esc closes it. The search and sort controls are added by JavaScript, so they are not displayed if it is unavailable, leaving the full set of cards in CSV order. Note that every card title is a heading, so a page using this feature will likely want "search_headings: false" in its front matter to keep each card from becoming its own site search result (see "docs/site_search_setup.md"). {% endcomment %} {%- assign cards_data = site.data[include.data] -%} {%- if cards_data.size > 0 -%} {%- assign bc_id = "browse-cards-" | append: include.data | slugify -%} {%- assign bc_heading = include.heading_level | default: "h2" | strip -%} {%- assign bc_label = include.label | default: "resources" | strip -%} {%- assign bc_total = cards_data | size -%} {%- assign bc_search = true -%} {%- if include.search == false or include.search == "false" -%}{%- assign bc_search = false -%}{%- endif -%} {%- assign bc_sort = true -%} {%- if include.sort == false or include.sort == "false" -%}{%- assign bc_sort = false -%}{%- endif -%}
