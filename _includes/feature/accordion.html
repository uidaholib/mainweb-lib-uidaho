{% comment %} Bootstrap accordion feature, https://getbootstrap.com/docs/5.1/components/accordion/ A simple accordion with no heading, built from numbered include parameters. For an accordion driven by a CSV of data, use "feature/faq.html" instead, it shares this styling. e.g. --> {% include feature/accordion.html title1="Example section" text1=example1 title2="Section two" text2=example2 title3="Section three" text3=example3 %} Options: - "title1", "title2", "title3" ... = title for each section of the accordion, numbered in order starting at 1, up to 12 sections. Numbers that are missing are skipped. - "text1", "text2", "text3" ... = text for the matching section, can use Markdown formatting. You will probably want to capture the text using a Liquid capture, then use the variable to provide text to this include. - "open" = optional, by default "false". Add "true" to have the first section open when the page loads. - "heading_level" = the heading element wrapping each section title, "h2", "h3", etc (default "h2"), set for correct heading order on the page. - "single" = optional, add "true" so that opening a section closes the others. By default any number of sections can be open at once, which matches uidaho.edu and lets people compare answers. - "id" = optional unique id for the accordion. One is generated automatically, so this is only needed if you want to link to the accordion. {%- endcomment -%} {%- assign acc_heading = include.heading_level | default: "h2" | strip -%} {%- if include.id -%} {%- assign acc_id = include.id | strip -%} {%- else -%} {%- capture acc_count %}{% increment accordionIncludeCount %}{% endcapture -%} {%- assign acc_id = "accordion-" | append: acc_count -%} {%- endif -%} {%- assign acc_open = false -%} {%- if include.open == true or include.open == "true" -%}{%- assign acc_open = true -%}{%- endif -%} {%- assign acc_single = false -%} {%- if include.single == true or include.single == "true" -%}{%- assign acc_single = true -%}{%- endif -%}
