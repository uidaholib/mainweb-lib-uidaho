{% comment %} Page Resources include is a standard page component found on the right side column of default page layout. It provides a list of resource links. These are generally external or deep links, supplementing than the standard page nav. It is a card box with grey background, a heading, and list of links. If the link is a file or external link, it has a icon at the end. This include is configured using page yaml front matter, page.page_resources keys. If a page has the page.page_resources key the layout will add this include automatically. Example YAML front matter configuration: page_resources: title: Resources links: - text: U of I Brand link: https://www.uidaho.edu/brand - text: Brand intranet pages link: https://vandalsuidaho.sharepoint.com/sites/InsideUI-UCM/SitePages/Brand.aspx - text: U of I Brand Book link: https://content-hub.uidaho.edu/api/public/content/226d8af4ad704e65a2e42d96613305b2?v=e636bbda {% endcomment %}
